Có cần máy chủ không?
Không — cho tới vài chục nghìn mục

Một từ điển tra được vẫn chạy trọn trong trình duyệt: dữ liệu là tệp tĩnh, tìm kiếm bằng JavaScript ngay tại máy người dùng. Y hệt kiến trúc bạn đang có, chỉ là từ điển to hơn. Chỉ khi vượt ~100.000 mục (cỡ đại từ điển) mới đáng cân nhắc backend.

국립국어원 · ~50.000 mục · CC-BY-SA

Từ điển cho người học của Viện Quốc ngữ Hàn Quốc. Có bản dịch tiếng Việt chính thức (1 trong 11 thứ tiếng), kèm định nghĩa, cấp độ, câu ví dụ. Tải cả bộ dạng XML. Đây là mỏ vàng.

KRDict theo CC-BY-SA 2.0 KR: bạn được dùng tự do, nhưng phải (1) ghi công 국립국어원, và (2) vì là « share-alike », bản từ điển phái sinh của bạn cũng phải mở dưới cùng giấy phép. Tatoeba là CC-BY (chỉ cần ghi công). Nhớ để một trang « Nguồn & giấy phép » trong app.

Cấu trúc mỗi mục từ

mở rộng từ schema hiện có, giữ tương thích ngược
// tương thích với {ko, rom, vi, pos, hanja, hv} đang dùng, chỉ thêm chiều sâu
word {
  ko           // 도서관
  rom          // doseogwan
  hanja, hv    // 圖書館 · đồ thư quán
  pos          // danh từ
  topik_level  // sơ / trung / cao cấp
  freq_rank    // xếp hạng phổ biến, để sắp kết quả
  senses[] {
    def_vi     // nghĩa tiếng Việt
    def_ko     // định nghĩa tiếng Hàn (cho người khá)
    examples[] { ko, vi }
    synonyms[], antonyms[]
  }
}

Điểm mấu chốt

Bạn không xây từ điển bằng cách gõ từng từ, mà bằng cách viết một script kéo KRDict về rồi làm giàu. Công nghệ tra cứu thì nhẹ và không cần server tới tận vài chục nghìn mục. Nút thắt duy nhất là công sức làm sạch dữ liệu và tôn trọng giấy phép CC-BY-SA.
